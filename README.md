# Cabin Crew 3D Portfolio

A premium, interactive 3D portfolio adapted for a female cabin-crew / air-hostess walk-in interview profile.

## What changed

- Replaced the original character implementation with an original procedural 3D female cabin-crew character.
- Added mouse/head interaction, idle motion, entrance animation and GSAP scroll-driven camera/character movement.
- Reworked the portfolio copy for cabin-crew recruitment: communication, customer service, teamwork, grooming, safety and interview readiness.
- Added eligibility-to-verify, walk-in document checklist and interview-practice sections.
- Removed developer-specific project/tech-stack content.
- Kept the original immersive single-page portfolio style and smooth scrolling approach.
- Added the supplied female reference image at `public/images/cabin-crew-reference.jpg` for future character modelling/reference work.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
